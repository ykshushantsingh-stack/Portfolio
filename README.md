# Shushant Kumar Singh - Portfolio

Plain HTML, CSS and JavaScript. No build step, no frameworks.

- index.html : page structure and content
- style.css  : colors (light/dark), layout, hero photo, terminal styles
- script.js  : live code wallpaper (canvas) with scroll parallax, and the JARVIS demo
- assets/photo.jpg : hero background photo

## Run locally
Open index.html in a browser. (Fonts load from Google Fonts, so you need internet.)

## Put it online for free (needed for LinkedIn)
1. GitHub Pages: create a repo, upload these files, then Settings > Pages > deploy from main branch.
   Your link will be https://YOUR-USERNAME.github.io/REPO-NAME/
2. Or Netlify Drop: drag this folder onto https://app.netlify.com/drop

## Add it to LinkedIn
- Profile > Contact info > Website: paste your link.
- Profile > Add section > Featured > Links: add your link with a title.
- Create a post and paste your link; LinkedIn shows a preview card.
